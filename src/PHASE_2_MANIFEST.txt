MEMORY LAYOUT SPECIFICATION
================================================================================

CPU State Block ($0300-$030D):
────────────────────────────
$0300: A Register (Accumulator)
$0301: X Register (Index X)
$0302: Y Register (Index Y)
$0303: S Register (Stack Pointer)
$0304: PC Low Byte (Program Counter)
$0305: PC High Byte (Program Counter)
$0306: P Register (Processor Status Flags)
$0307: Current Opcode
$0308: Addressing Mode Type
$0309: Effective Address Low
$030A: Effective Address High
$030B: Operand Value Low
$030C: Operand Value High
$030D: Addressing Mode Flags

Zero Page Work Space ($00-$03):
────────────────────────────────
$00-$01: Primary indirect address pointer
$02-$03: Secondary indirect address pointer

Stack ($0100-$01FF):
─────────────────────
S register points into this range
Used for return addresses, flags, register saves

Program Memory ($2000-$9FFF):
──────────────────────────────
General purpose program execution space

ROM ($E000-$FFFF):
────────────────────
$E000-$E7FF: Boot and diagnostics
$E800-$EFFF: Monitor and utilities
$F000-$FFFF: Additional ROM space
$FFFA-$FFFB: NMI Vector
$FFFC-$FFFD: RESET Vector
$FFFE-$FFFF: IRQ Vector

Diagnostic Output ($0400-$0409):
──────────────────────────────────
$0400: A Register copy
$0401: X Register copy
$0402: Y Register copy
$0403: S Register copy
$0404: PC Low copy
$0405: PC High copy
$0406: P Register copy
$0407: Current Opcode copy
$0408-$0409: Cycle counter

================================================================================
PROCESSOR STATUS FLAGS (P Register)
================================================================================

Bit 7: N (Negative) - Set if result bit 7 = 1
Bit 6: V (Overflow) - Set on signed arithmetic overflow
Bit 5: R (Reserved) - Always = 1 on 6502
Bit 4: B (Break)    - Set when BRK executed
Bit 3: D (Decimal)  - Set for decimal mode (BCD)
Bit 2: I (Interrupt) - Set when interrupts disabled
Bit 1: Z (Zero)     - Set if result = $00
Bit 0: C (Carry)    - Set if result > $FF (or borrow flag)

Initial P value: $34 (%00110100)
- R=1, B=0, D=0, I=0, Z=0, C=0

ADDRESSING MODES IMPLEMENTED
================================================================================

1. IMPLIED ($00)
   No operand, PC advances by 1
   Examples: BRK, NOP, RTS, RTI, TAX, TYA, etc.

2. ACCUMULATOR ($01)
   Operates on A register, PC advances by 1
   Examples: ASL A, LSR A, ROL A, ROR A

3. IMMEDIATE ($02)
   Operand is next byte, PC advances by 2
   Examples: LDA #$FF, ADC #$01, CMP #$00

4. ZERO PAGE ($03)
   Address is in zero page, PC advances by 2
   Examples: LDA $80, STA $7F, INC $40

5. ZERO PAGE,X ($04)
   Address = (byte + X) & $FF, PC advances by 2
   Examples: LDA $80,X, STA $7F,X, INC $40,X

6. ZERO PAGE,Y ($05)
   Address = (byte + Y) & $FF, PC advances by 2
   Examples: LDX $80,Y, STX $7F,Y (limited use)

7. ABSOLUTE ($06)
   16-bit address (little-endian), PC advances by 3
   Examples: JMP $E000, LDA $8000, STA $C000

8. ABSOLUTE,X ($07)
   Address = 16-bit + X (with carry), PC advances by 3
   Examples: LDA $8000,X, STA $C000,X, INC $6000,X

9. ABSOLUTE,Y ($08)
   Address = 16-bit + Y (with carry), PC advances by 3
   Examples: LDA $8000,Y, STA $C000,Y

10. INDIRECT ($09)
    JMP ($nnnn) - Read 16-bit target from address
    Examples: JMP ($E100)

11. (INDIRECT,X) ($0A)
    Address = (ZP + X) with 16-bit read, PC advances by 2
    Examples: LDA ($80,X), STA ($7F,X), ADC ($60,X)

12. (INDIRECT),Y ($0B)
    Address = (ZP) + Y where (ZP) is 16-bit, PC advances by 2
    Examples: LDA ($80),Y, STA ($7F),Y, AND ($60),Y

13. RELATIVE ($0C)
    Signed 8-bit offset for branches, PC advances by 2
    Examples: BEQ $E100, BMI label, BNE loop

OPCODE TABLE MAPPING
================================================================================

The OPCODE_TABLE ($xxxx) contains 256 entries (512 bytes for 16-bit pointers):

Format: .WORD handler_address for each opcode $00-$FF

Dispatch mechanism:
  LDA opcode            ; Load opcode value
  ASL A                 ; Multiply by 2 for word index
  TAX                   ; Use as index
  LDA OPCODE_TABLE, X   ; Load handler address low byte
  STA $80
  INX
  LDA OPCODE_TABLE, X   ; Load handler address high byte
  STA $81
  JMP ($80)             ; Jump to handler

All 256 entries mapped:
  • 151 valid opcodes → functional handlers
  • 105 invalid opcodes → NOP handler
