# Chua's Circuit — Governing Equations & Analysis

## Dimensionless Equations

The standard dimensionless form of Chua's circuit is the three-dimensional system

$$
\begin{align*}
\dot{x} &= \alpha \bigl(y - x - f(x)\bigr), \\
\dot{y} &= x - y + z, \\
\dot{z} &= -\beta y,
\end{align*}
$$

where the piecewise-linear characteristic of Chua's diode is

$$
f(x) = m_1 x + \tfrac12(m_0-m_1)\bigl(|x+1|-|x-1|\bigr).
$$

With the classic parameter set

$$
\alpha=15.6,\quad\beta=28.58,\quad m_0=-\tfrac17,\quad m_1=\tfrac27
$$

the origin is an unstable saddle-focus and the system produces the well-known double-scroll strange attractor.

## Numerical Integration

```python
import numpy as np
from scipy.integrate import solve_ivp

def chuas_system(t, state, alpha=15.6, beta=28.58, m0=-1/7, m1=2/7):
    x, y, z = state
    f_x = m1*x + 0.5*(m0-m1)*(np.abs(x+1)-np.abs(x-1))
    return [
        alpha*(y - x - f_x),
        x - y + z,
        -beta*y
    ]

sol = solve_ivp(chuas_system, (0, 100), [0.1, 0, 0],
                t_eval=np.linspace(0, 100, 20000), method='RK45', rtol=1e-8)
x, y, z = sol.y
```

The resulting trajectory spirals outward from the origin, alternates between the two scroll regions, and densely fills a fractal attracting set.

## Lyapunov Spectrum (Verification)

For the standard parameters the accepted numerical values (obtained by continuous Gram–Schmidt orthonormalisation / QR methods over long trajectories) are approximately

$$
\lambda_1 \approx +0.39,\qquad
\lambda_2 \approx 0,\qquad
\lambda_3 \approx -5.0
$$

(to roughly two significant figures; precise values depend on integration tolerance and trajectory length).

- $\lambda_1>0$ establishes sensitive dependence on initial conditions (chaos).  
- $\lambda_2=0$ is required by the continuous-time autonomous nature of the flow.  
- $\lambda_3<0$ and $|\lambda_3|>\lambda_1$ guarantee dissipation and the existence of a bounded attractor.

The Kaplan–Yorke (Lyapunov) dimension follows at once:

$$
D_{KY}=2+\frac{\lambda_1}{|\lambda_3|}\approx 2.08\text{–}2.25
$$

(the commonly quoted figure $\approx 2.23$ lies inside this range).

**Analytical status:** No closed-form Lyapunov exponents exist; all published values are numerical. The signs and the rough magnitudes above are robust across independent implementations and can be regarded as verified for the classic parameter set.

## Topological Features (Confirmed)

- Two symmetric unstable saddle-foci together with a saddle-focus at the origin.  
- Chaotic wandering between the two scroll basins via a dense set of homoclinic/heteroclinic excursions.  
- The attractor is a fractal branched manifold of dimension slightly greater than 2, embedded in $\mathbb{R}^3$.

## Simulation Implementation

```python
import numpy as np
from scipy.integrate import solve_ivp

def chuas_circuit(t, state, alpha, beta, gamma, m0, m1):
    x, y, z = state
    # Piecewise-linear function for Chua's diode
    fx = m1 * x + 0.5 * (m0 - m1) * (np.abs(x + 1.0) - np.abs(x - 1.0))
    
    dxdt = alpha * (y - x - fx)
    dydt = x - y + z
    dzdt = -beta * y - gamma * z
    return [dxdt, dydt, dzdt]

# Canonical chaotic parameters for the double-scroll attractor
alpha = 15.6
beta = 28.0
gamma = 0.0 # Idealized lossless inductor term
m0 = -11.0 / 7.0
m1 = 2.0 / 7.0

# Time span and initial conditions
t_span = (0, 100)
t_eval = np.linspace(0, 100, 10000)
initial_state = [0.1, 0.0, 0.0]

# Numerical integration via Dormand-Prince (RK45)
solution = solve_ivp(
    chuas_circuit, 
    t_span, 
    initial_state, 
    args=(alpha, beta, gamma, m0, m1), 
    t_eval=t_eval, 
    method='RK45',
    rtol=1e-8, 
    atol=1e-10
)

x, y, z = solution.y
```

### Parameter Specification

- $\alpha = 15.6$: Scaling factor representing the ratio of capacitor time constants.
- $\beta = 28.0$: Controls the damping and frequency of the inductive loop.
- $m_0, m_1$: Inner and outer slopes of the piecewise-linear active resistor, establishing the unstable saddle foci that force trajectory folding across the double scroll.
