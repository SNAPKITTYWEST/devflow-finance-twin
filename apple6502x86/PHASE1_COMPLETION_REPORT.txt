PHASE 1 BOOT SEQUENCE WITH DIAGNOSTICS
================================================================================

1. Power on / RESET → $FFFC vector → RESET_HANDLER ($E000)
2. CPU_INIT: Initialize A, X, Y, SP, flags
3. MEM_INIT: Zero page, stack, RAM initialization
4. ROM_INIT: Vector table setup, checksum initialization
5. Enable interrupts (CLI)
6. JMP MONITOR_ENTRY ($E800)
7. MONITOR_ENTRY calls PHASE1_BOOT_DIAGNOSTICS ($E700)
8. Execute 12 checkpoints with status reporting
9. If all pass: PHASE1_COMPLETE = $01, continue to PHASE 2
10. If any fail: BOOT_DIAG_STATUS = error code, JMP HALT

On Success:
    - BOOT_DIAG_STATUS = $00
    - PHASE1_COMPLETE = $01
    - All 12 checkpoint status variables = $01
    - System continues to PHASE 2

On Failure:
    - BOOT_DIAG_STATUS = error code ($01-$0B)
    - CHECKPOINT_N_STATUS = $00 (failed checkpoint)
    - System enters BOOT_DIAG_HALT (infinite loop)
    - Error code available for debugging
