[✓] detect_negative_cycles()

    Code Location:

      Go:   BinaryBuilder.detectNegativeCycles() @ polyglot_builder.go:445
    Algorithm: DFS-based cycle detection
      graph := {}
      FOR each rule:
        head_pred := predicate_id(rule.head[0].atom)
        FOR each literal IN rule.body:
          body_pred := predicate_id(literal.atom)
          edge := (body_pred, is_positive=literal.positive)
          graph[head_pred] ∪= edge

      visited := {}, rec_stack := {}
      FOR each node IN graph.keys():
        IF NOT visited[node]:
          dfs_visit(node, graph, visited, rec_stack)

      dfs_visit(node, graph, visited, rec_stack):
        visited[node] := true
        rec_stack[node] := true
        FOR each (edge_to, is_positive) IN graph[node]:
          IF NOT visited[edge_to]:
            dfs_visit(edge_to, graph, visited, rec_stack)
          ELSE IF rec_stack[edge_to] AND NOT is_positive:
            RETURN ERR_NEGATIVE_CYCLE  // Cycle with negation!
        rec_stack[node] := false
    Fail Action: Return ERR_NEGATIVE_CYCLE (recover=false, first cycle)

================================================================================
FAIL-CLOSED ENFORCEMENT (All Languages)
================================================================================

Error Recovery Policy:
  - Phase 1 (Structural): recover=false (fatal)
  - Phase 2 (Symbol): recover=false (fatal)
  - Phase 3 (Safety): recover=false (fatal)
  - Phase 4 (Semantics): recover=false (fatal, except recursion/choice warnings)
  - Phase 5 (Binary): recover=false (fatal)

Validation Chain:
  1. Check Phase 1; if fail → return immediately
  2. Check Phase 2; if fail → return immediately
  3. Check Phase 3; if fail → return immediately
  4. Check Phase 4; if fail → return immediately (warnings don't stop)
  5. Check Phase 5; if fail → return immediately
  6. Return SUCCESS with ValidatedAST

Error Reporting:
  - Every function returns explicit error code (not implicit success)
  - Error includes: code, message, phase, recovery flag
  - Caller must check status before using result
