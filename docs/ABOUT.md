## Research Philosophy

The system explores the reduction of relational logic into a compact
recursive-step computational model. Every component is:

1. **Deterministic**: Pure functions, no side effects
2. **Bounded**: Fixed-width state, O(1) stack
3. **Sealed**: Append-only log with FNV-1a-64 integrity
4. **Verified**: Formal proofs where possible, bounded checks elsewhere
