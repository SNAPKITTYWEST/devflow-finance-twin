# RSI and Lua audit

Scope: `dream_rsi/`, its four existing test files, and all six files in `lua/`.
This is a source audit with local execution, not a claim of production readiness.
The exact tested source hashes, runtime, machine, revision, raw timings, and Lua
check outcomes are in [benchmark results](../../benchmarks/rsi_lua/results/latest.json).

Final scoped results: 29 RSI tests passed and eight strict expected failures
reproduced unresolved defects. Lua had five passing checks and 18 failing checks
across both codec copies and integration/example checks. Seventeen RSI workloads
and eight Lua microbenchmarks produced timings. This was not a whole-repository test run.

## What changed

Eight flat RSI modules collided with package directories of the same names.
Before organization, all four RSI test files failed collection with a circular
`RunMetrics` import. Each flat module now lives at `<package>/legacy.py`.
The files were hash-verified during relocation; only relative imports were
adjusted afterward. [Relocation manifest](rsi-relocations.json) records original
hashes. Both implementation generations remain available. Package exports keep
the first implementation's tested entry points usable while layered APIs remain
available through their explicit modules. See [RSI layout](../../dream_rsi/README.md).
All eight relocated implementation bodies and all six unchanged Lua source files
passed [source-preservation checks](organization-verification.json).

The audit corrected two existing test assertions: offline evaluations count
policy revisions, not discovery calls; incumbent selection guarantees apply to
the same historical pool, not successive pools with different worlds.
No search, scoring, persistence, or Lua wire-format algorithm was changed.

## RSI findings

| ID / priority | Evidence and edge case | Status / consequence |
|---|---|---|
| RSI-01 / high | Flat files and same-name packages produced import collisions; `metrics/` lacked `__init__.py`. | Fixed through organization and compatibility exports; both generations import. |
| RSI-02 / high | `core/orchestrator.py:explore_online` checks total nodes outside the branch loop. `max_nodes=3`, branch factor 2, budget 20 creates 4 non-root nodes. The legacy loop has the same outer-only check. | Open; strict expected-failure test for the layered implementation. Enforce remaining global capacity before each proposal. |
| RSI-03 / high | `tree.py:validate` checks forward child links but accepts disconnected nodes and a root self-cycle. `from_dict` also overwrites duplicate node IDs and does not validate. | Open; orphan and cycle failures reproduced. Validate root, unique IDs, reachability, acyclicity, and both directions of every edge. |
| RSI-04 / high | `SimulationBudget.max_worlds` is never consumed by `HistoricalReplay.replay`. Passing two worlds with a one-world budget still replays both. | Open; explicit `max_worlds` argument is a separate slice, and negative values are not rejected. Node/cost limits restart per world, not globally. |
| RSI-05 / high | `WorldSimulator.run` adds a node's full cost before checking exhaustion. A cost-10 child is charged with `max_cost=1`. Online custom execution costs are also known only after execution. | Open; replay overspend reproduced. Define admission and unknown-cost semantics before claiming hard budgets. Root counts toward replay node limits, unlike online non-root limits. |
| RSI-06 / medium | `SearchPolicy(budget=NaN)` passes validation. `parallel_group_size` is not validated. `evaluation/protocol.py:validate_score` rejects nonfinite scores but orchestration never calls it. | Open; NaN budget reproduced. Score validity and evaluator `valid` flags do not gate selection. |
| RSI-07 / medium | `SimulatorPool.bounded(0)` uses `[-0:]`. | Open; returns the entire pool, not an empty pool. Reject negative limits and define zero explicitly. |
| RSI-08 / medium | Legacy `DreamRSI.run` ignores `RunConfig.revisions` and `online_budget`. | Open; requesting zero revisions still evaluates candidates. CLI uses this legacy implementation. |
| RSI-09 / medium | Both proposal hashes include a parent node ID generated by UUID. Online code uses FIFO regardless of requested branch ordering; parallel-group fields do not launch workers. | Source-confirmed. Runs are not reproducible from task alone, and replay ordering can differ from online behavior. Benchmarks explicitly substitute repeatable IDs. |
| RSI-10 / medium | Both JSONL stores validate before append but `load` only deserializes. Historical wrappers and pool snapshots retain mutable tree references. | Source-confirmed. Malformed semantic trees can load; callers can mutate previously recorded worlds. No file lock, atomic append protocol, or crash recovery is implemented. |
| RSI-11 / medium | `policy_improvement` compares results from different pools; replay counters omit incumbent evaluations. Baseline metrics do not populate all fields comparably. | Source-confirmed. Do not interpret this field as isolated policy improvement or compare baseline wall-clock fields as measured runtime. |
| RSI-12 / scope | Domain evaluators score hash fragments. No algorithm compilation, mathematical solver, GPU execution, or model-training operation occurs. | These are synthetic controller experiments. The fixed-pool incumbent guarantee is not generalization or real task improvement. |

Eight unresolved cases are executable strict `xfail` tests in
[test_dream_rsi_audit.py](../../tests/test_dream_rsi_audit.py). They assert desired
behavior and currently fail; `XPASS` becomes a failure so a repair cannot silently
leave a stale expected-failure marker. They are not eight passing correctness checks.
The [test log](rsi-test-results.txt) records the current run.

## Lua findings

Both `metabinary.lua` and `metabinary_complete.lua` contain their own codec.
They share the following failures; tests exercise both copies independently.

| ID / priority | Evidence and edge case | Status / consequence |
|---|---|---|
| LUA-01 / high | `header_pack` emits 28 bytes; `header_size`, minimum-input gates, and introspection assume 32. | Reproduced. An empty-parameter leaf cannot deserialize its own serialized bytes. Do not select 28 or 32 as the canonical ABI without checking native alignment and the intended format. |
| LUA-02 / high | `deserialize` returns the next one-based offset, then its parent adds that value as consumed bytes. `validate` skips only a child header and parameters, not its subtree. | Off-by-one count and two-child round-trip failures reproduced. Nested siblings need an exact recursive consumed-length contract. |
| LUA-03 / high | `validate` does not call `verify_integrity`. That helper hashes a header containing the populated checksum, while serialization hashed a zero checksum. The hash named `blake3_hash` is a polynomial mock. | Reproduced tampering acceptance, with trailing bytes to satisfy the existing header gate. There is no BLAKE3 authentication or reliable integrity validation. |
| LUA-04 / high | `builder.new` returns a plain table without the builder metatable. | Reproduced; fluent `:set_dimensions` calls fail, including high-level example factories. |
| LUA-05 / medium | `(#ast.params or "")` takes the length before applying the default. Passing numeric `(flags & 4)` as a boolean treats zero as true. | Missing parameters throw; an impure leaf acquires the pure bit. Both reproduced. |
| LUA-06 / high | `example_usage_all_backends.lua` is missing a closing parenthesis on its summary `print`. | Syntax check recorded. The example timings also do not assert deserialize/validate success and cannot serve as benchmark evidence. |
| LUA-07 / medium | Facade `Builder:serialize` returns an AST table. `Builder:validate` rebuilds flags without retaining the pure bit. ENCODE's documented `u64 + u16 + u8` is 11 bytes, but expected length is 9. | AST-return behavior reproduced; remaining points are source findings. |
| LUA-08 / high | FFI library loaders assign a `.so` default before checking Windows/OSX, so later `or` defaults cannot select platform filenames. C error handling invokes `ffi.string` before confirming a non-null error pointer. | Source-confirmed; native failure/ownership paths remain untested. Explicit library paths avoid only the filename issue. |
| LUA-09 / high | Final assembly serializes in Lua even when a native backend name is selected; optional Rust validation treats a returned result object as success without checking status. The complete module's backend registration only sets flags. | Backend labels do not establish native execution. No definitions of the declared `c_serialize_block`, `rust_serialize_block`, or `go_serialize_block` symbols were found outside Lua by tracked-source search. Native backend benchmarks were not run. |
| LUA-10 / medium | Recursive serialization/query functions have no cycle/depth guard. Deserialization does not invoke semantic validation, and validation does not enforce exact end-of-buffer consumption. | Source-confirmed. Add limits, trailing-data policy, integer/range checks, and cyclic-AST rejection before processing untrusted trees. |

The harness uses installed MiKTeX `texlua`, which reports Lua 5.3 and can load this
installation's FFI module. Successful final-assembly loading does not prove that
a native backend library loaded or that its ABI is correct. Stock Lua/LuaJIT and
other platforms were not tested.

## Benchmark interpretation

The runner measures 17 RSI workloads: both orchestrators, layered revision counts
0/4/8 across 1/10/50 rounds, replay of 1/10/100 copies of a fixed 63-node tree,
JSON round trip, and JSONL round trip. Each has a warm-up followed by seven samples
of five operations. Result counters must match between repetitions. The JSONL
measurement includes temporary-directory and file lifecycle overhead.

Eight Lua microbenchmarks measure header packing, serialization alone, decoding
256 NAND words, and leaf node counting for both codecs. Each has 100 warm-up
operations and seven timed samples. Lua timings use `os.clock` CPU seconds;
Python uses `perf_counter_ns` wall time. Do not compare those clocks directly.
Header and serializer timings explicitly measure the current invalid wire format;
successful round-trip, integrity-validation, and native-backend throughput remain
unavailable. Separate checks exhaustively round-trip all 65,536 NAND words; this
tests bit preservation, not ISA execution or legal-opcode validation.

See [benchmark instructions and measured summary](../../benchmarks/rsi_lua/README.md).
Timings are local observations, not speedup claims. The driver exits nonzero on
benchmark execution failures; expected audit failures remain explicit records in
the JSON and must be inspected separately.
